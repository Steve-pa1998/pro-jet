**Scraper con Scrapy para https://quotes.toscrape.com/**  
El objetivo es extraer **texto** y **autor** de cada cita y guardarlo en un archivo **CSV**.  
Solo se realizan peticiones **GET**, se respeta un **delay de 2 s** entre peticiones y el proyecto está listo para ejecutarse con `scrapy crawl quotes`.

### 2.8 `quotes_scraper/spiders/quotes_spider.py`

```python
# quotes_scraper/spiders/quotes_spider.py
# Spider que recorre todas las páginas de https://quotes.toscrape.com/
# y extrae el texto de la cita y el nombre del autor.

import scrapy
from ..items import QuoteItem


class QuotesSpider(scrapy.Spider):
    """Spider que extrae citas y autores de quotes.toscrape.com."""
    name = 'quotes'                     # Nombre con el que se invoca: scrapy crawl quotes
    allowed_domains = ['quotes.toscrape.com']
    start_urls = ['https://quotes.toscrape.com/']   # Punto de partida (solo GET)

    def parse(self, response):
        """
        Callback principal.
        - Recorre todas las citas de la página actual.
        - Sigue el enlace a la siguiente página (si existe).
        """
        # ------------------------------------------------------------------
        # 1. Extraer cada cita de la página
        # ------------------------------------------------------------------
        for quote_sel in response.css('div.quote'):
            # Cada cita tiene la estructura:
            #   <span class="text">“...texto...”</span>
            #   <small class="author">Autor</small>
            item = QuoteItem()
            # .get() devuelve el primer elemento encontrado o None.
            # .strip() elimina espacios en blanco al inicio/final.
            item['text'] = quote_sel.css('span.text::text').get().strip('“”')
            item['author'] = quote_sel.css('small.author::text').get().strip()
            yield item

        # ------------------------------------------------------------------
        # 2. Navegar a la página siguiente (si existe)
        # ------------------------------------------------------------------
        next_page = response.css('li.next > a::attr(href)').get()
        if next_page:
            # `response.urljoin` construye la URL absoluta a partir del href relativo.
            yield scrapy.Request(
                url=response.urljoin(next_page),
                callback=self.parse,
                method='GET'   # explícito, aunque GET es el valor por defecto
            )
```

## 3. Instrucciones para ejecutar el scraper

1. **Crear un entorno virtual (recomendado)**  

   ```bash
   python -m venv venv
   source venv/bin/activate   # Linux/macOS
   # .\venv\Scripts\activate   # Windows
   ```

2. **Instalar Scrapy**  

   ```bash
   pip install scrapy
   ```

3. **Colocar la estructura de carpetas**  
   Copia los archivos mostrados arriba manteniendo la jerarquía exacta.

4. **Ejecutar el spider**  

   ```bash
   cd quotes_scraper          # Directorio donde está scrapy.cfg
   scrapy crawl quotes
   ```

   - El spider recorrerá todas las páginas del sitio, esperará **2 s** entre cada petición y generará un archivo **`quotes.csv`** en el mismo directorio.

5. **Resultado**  
   El CSV tendrá dos columnas: `text` y `author`. Un ejemplo de fila:

   ```
   text,author
   The greatest glory in living lies not in never falling, but in rising every time we fall.,Nelson Mandela
   ```

## 4. Suposiciones y notas adicionales

| # | Suposición | Comentario |
|---|------------|------------|
| 1 | El sitio mantiene la misma estructura HTML que al momento de escribir este código. | Si la página cambia, los selectores CSS (`div.quote`, `span.text`, `small.author`) deberán actualizarse. |
| 2 | No se requieren cabeceras especiales (User‑Agent, etc.). | Scrapy envía un User‑Agent genérico; si el sitio lo bloquea, se puede añadir `USER_AGENT` en `settings.py`. |
| 3 | No se necesita manejo de errores avanzado (p.ej., reintentos). | Scrapy ya reintenta automáticamente peticiones fallidas (por defecto 2 veces). |
| 4 | El archivo CSV se sobrescribe en cada ejecución. | Si se desea *append*, cambiar `FEED_URI = 'quotes.csv'` a `FEED_URI = 'quotes.csv?append=true'`. |
| 5 | No se guardan datos duplicados. | El sitio no repite citas entre páginas, por lo que no se implementa deduplicación. |

## 5. Extensiones posibles (opcional)

- **Rotación de User‑Agent** mediante un middleware para evitar bloqueos.
- **Exportar a JSON** cambiando `FEED_FORMAT` a `json` o `jsonlines`.
- **Almacenar en base de datos** (SQLite, PostgreSQL) mediante un pipeline personalizado.
- **Uso de `scrapy crawl quotes -o quotes.csv`** como alternativa a la configuración de `FEED_*` en `settings.py`.
