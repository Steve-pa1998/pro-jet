CampoQué esEjemplo
lenguajeEn qué lenguaje se escribePython

salidaEn qué formato guardaCSV / JSON / SQLite
límiteMáximo de páginas o registros200 páginas
user_agentQué "navegador" dice que es"Mozilla/5.0 (Windows NT 10.0...)"
whitelistSolo estos dominiosejemplo.com
blacklistNunca navegar a*.exe, *.bat, *.sh

¿Qué es cada cosa?

TérminoExplicación simple
BeautifulSoupUn parser. Lee el HTML y te deja buscar elementos. Como Ctrl+F pero estructurado. "Dame todos los <span class='phone'>"
PlaywrightAbre un navegador REAL (Chromium). Espera que cargue todo. Para páginas que necesitan JavaScript (React, Facebook, Google Maps).
Solo GET"Solo mira, no toques nada." No envía formularios, no hace login, no borra. Es como abrir una pestaña.
Timeout 10sSi la página no responde en 10 segundos, deja de esperar y pasa a la siguiente. Para que tu script no se quede colgado.
Sleep 2sDespués de cada petición, espera 2 segundos. Para que no te detecten como bot. Simula un humano navegando lento.
extraiga []Los campos de TU base de datos + dónde están en la página. Tú le dices QUÉ buscar, él busca DÓNDE.
dominioLa URL base. De dónde saca los datos. Si es Google Maps → usa API oficial. Si es Facebook → no se puede.

Template lleno (copia y pega a codi)

# SPEC — Scraper lenguaje: Python parser: BeautifulSoup método: GET dominio: https://directorio-ejemplo.com/negocios extraiga: - nombre (h2 con class="biz-name") - telefono (a con href="tel:") - ciudad (span con class="city") - comportamiento (p con class="description") timeout: 10s sleep: 2s salida: CSV límite: 200 páginas user_agent: "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36" whitelist: directorio-ejemplo.com blacklist: *.exe, *.bat, *.sh, *.py
⚠️ Legal: Scraping de datos personales (teléfono + nombre + edad) sin consentimiento es ilegal en México (LFPDPPP). Google Maps y Facebook tienen APIs oficiales. Úsalas.

8. ¿Qué es qué?

TérminoQué esEjemplo
System promptEl "rol" que le das al LLM. Le dice cómo comportarse."Eres un optimizador de código..."
Tool / HerramientaUna función que el LLM puede llamar. Sus "manos".leer_archivo, navegador, hablar
FrameworkEstructura que organiza agentes y su comunicación.Tu bus.py + cordi.py. O LangChain.
AgenteUn programa que tiene un LLM + tools + un rol.asiste.py, codi.py
BusEl "tablero de notas" donde se pegan órdenes y estados.bus.jsonl, orders.jsonl
RAGBuscar en documentos guardados por similitud (no por texto exacto).ChromaDB + nomic-embed-text
EmbeddingTraducir texto → números para que se pueda "buscar por parecido".nomic-embed-text (Ollama local)
LLMEl modelo de lenguaje. El "cerebro" que genera texto.Groq (nube), Ollama (local)
Tool callingEl LLM decide "necesito llamar a la función X con estos parámetros".Groq devuelve {"function": "navegador", "args": {...}}
SubprocessEjecutar un programa desde otro. "Corre este archivo como si lo corrieras en la terminal".cordi.py lanza codi.py

10. Config y estructura de archivos

pro jet/ ├── env/ │ ├── __init__.py ← "from env.config import *" │ ├── config.py ← paths, modelo, URL de Groq │ └── keys.env ← GROQ_API_KEY=... ├── agents/ │ └── codi.py ← agente de código ├── asiste.py ← asistente personal (loop) ├── bus.py ← bus de mensajes (JSONL) ├── bus.jsonl ← estados de agentes ├── orders.jsonl ← órdenes del cerebro └── context/ ├── logs/ ← logs de cada agente ├── output/ ← código generado por codi └── screenshots/ ← capturas de pantalla

Reglas

ReglaPor qué
Todo .py importa de envUna sola fuente de verdad. Si cambias la key, cambias 1 archivo.
Bus es append-only (JSONL)Nadie reescribe líneas. Solo se agregan. No se corrompe.
Cordi NO es LLMEs un script de 50 líneas. Si le pones LLM, "piensa" cosas que no debe.
Cere NO ejecutaSolo escribe órdenes. Si ejecuta, está haciendo el trabajo de cordi.
1 agente = 1 archivo = 1 main()Sin wrappers, sin importlib, sin registry.
3-5 tools por agenteMás de 5 y el modelo se confunde eligiendo.

11. Groq (tu GPU en la nube)

DatoValor
Modeloopenai/gpt-oss-120b
URLhttps://api.groq.com/openai/v1/chat/completions
CostoGratis (free tier)
Límite30 requests/min, 1,000/día
Velocidad~500 tokens/segundo
Tool callingSí (mismo formato OpenAI)
Tu keyenv/keys.env (nunca en el código)
Por qué Groq y no Ollama: Tu PC tiene AMD Radeon integrada (2 GB, comparte RAM). No puede correr modelos 7B+ a velocidad usable. Groq corre en la nube, es gratis, y el modelo es 120B (10x más grande que cualquier cosa local).
Ollama local solo para: nomic-embed-text (274 MB, trivial, para hacer embeddings de ChromaDB).
